## 1. Guion con tiempos

| Tiempo | Bloque | Narración |
|---|---|---|
| 0,0–3,4 | **Gancho** | Si el mar te arrastra, nadar hacia la orilla puede ser tu peor error. |
| 3,4–5,8 | Desarrollo | Es una corriente de resaca. |
| 5,8–9,2 | | Las olas empujan agua hacia la playa, y esa agua tiene que volver. |
| 9,2–12,2 | | Lo hace por un canal estrecho, como un río dentro del mar. |
| 12,2–17,0 | | Y puede ir a casi dos metros y medio por segundo: más rápido que un nadador olímpico. |
| 17,0–19,6 | | Si luchas contra ella, te agotas. |
| 19,6–23,0 | | Así que, paso uno: calma. Flota y respira. |
| 23,0–29,0 | | Paso dos: nada en paralelo a la orilla. Estos canales suelen medir menos de veinticinco metros de ancho. |
| 29,0–33,2 | | Paso tres: cuando ya no tire, vuelve a la playa en diagonal. |
| 33,2–37,0 | | ¿Y si no puedes salir? Flota, levanta el brazo y pide ayuda a gritos. |
| 37,0–40,6 | | ¿Cómo detectarla? Busca una franja donde las olas no rompen, |
| 40,6–44,2 | | …con agua más oscura, o con espuma y arena saliendo mar adentro. |
| 44,2–46,0 | **Giro** | Y ahora, el giro: |
| 46,0–49,4 | | mucha gente cree que estas corrientes te hunden. Falso. |
| 49,4–52,6 | | No te tiran hacia abajo: te alejan de la orilla. |
| 52,6–55,6 | | Lo que agota es el pánico. Saber esto puede salvarte. |
| 55,6–59,0 | **Cierre / CTA** | Guárdalo, compártelo con quien va a la playa y sígueme para más. |

**Dirección de voz:** el gancho, serio y directo, con un punto de urgencia. Los "paso uno, dos, tres" se dicen marcados y con energía, como un entrenador. En el giro, "Falso." seco, tras una micro-pausa. El cierre, cálido. El tema es serio: **humor solo en lo visual** (Nico cómico, pero nunca burlándose del peligro).

## 4. Música
- **Género:** *electro-pop* de tensión suave o *cinematic pulse* (sintes con *arpeggio*) en el desarrollo. En los pasos, una base de percusión más marcada, tipo tutorial.
- **BPM:** 120–125. Los números de "paso" (escenas 16, 18 y 21) caen en el primer tiempo del compás.
- **Mezcla:** −20 dB bajo la voz. La música baja a −28 dB durante "pide ayuda a gritos" para dar peso a la frase. Corte en seco con el *record scratch* (escena 30) y entrada de un *pad* luminoso para el cierre.
- Busca: "tension pulse", "upbeat tutorial", "summer electronic".

## 5. Fuentes
1. **Velocidad de hasta 8 pies/s (≈2,4 m/s), más rápido que un nadador olímpico; nadar en paralelo a la orilla:** NOAA Ocean Service, ["What is a rip current?"](https://oceanservice.noaa.gov/facts/ripcurrent.html). *Ojo:* es la velocidad máxima medida; lo habitual son 0,3–0,6 m/s. Por eso el guion dice "**puede** ir a…".
2. **La mayoría de canales miden menos de 80 pies (≈24 m) de ancho; no luchar contra la corriente; flotar y pedir ayuda:** NOAA SciJinks, ["How do I escape rip currents?"](https://scijinks.gov/rip-currents).
3. **Mito: "las corrientes de resaca te hunden". Realidad: te alejan de la orilla, no te hunden:** National Weather Service, [Rip Current FAQs (PDF)](https://www.weather.gov/media/safety/ripcurrent_faqs.pdf) y [mitos de las corrientes de resaca](https://caseagrant.ucsd.edu/news/three-myths-about-rip-currents) (California Sea Grant, UC San Diego).
4. **Cómo detectarlas (hueco sin olas rompiendo, agua más oscura, espuma o sedimento hacia mar adentro):** NWS, [folleto sobre corrientes de resaca (PDF)](https://w2.weather.gov/media/owlie/rip_brochure_51419b.pdf).
